# Greg Tizhe Zirra's Calculator

A calculator web application with a **MODULO operator** as the unique feature, complete with a CI/CD pipeline.

## Features
- Basic arithmetic (+, -, *, /)
- **MODULO operator (%)** - My unique feature
- Decimal support
- Clear and backspace functions
- Responsive design

## CI/CD Pipeline
This project includes a complete CI/CD pipeline with:
1. ESLint code quality checks
2. Jest unit tests (41 tests covering all functionality)
3. npm security audit
4. Multi-stage Docker build
5. FTPS deployment to VPS
6. Automated verification
